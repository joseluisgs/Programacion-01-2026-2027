# VÍDEO 2: Tipos de Datos, Variables y Operaciones (15 min)

## Para NotebookLM: Generar Vídeo de Clasificación

Crea un vídeo de contenido para la asignatura Programación del CFGS de Desarrollo de Aplicaciones Web, primer curso, curso 2026/2027, en el IES Luis Vives de Leganés. El profesor es José Luis González Sánchez.

Duración: 15 minutos. Idioma: español de España (castellano), nunca otra variante. Voz masculina. Tono didáctico y cercano.

Metáfora visual: "La Cocina". Ingredientes = tipos de datos, vasijas = variables, receta = operaciones, termostato = comparaciones.

PORTADA: Título EXACTO "Tipos de Datos, Variables y Operaciones". Subtítulo: Programación · 1DAW · IES Luis Vives de Leganés · 2026/2027. Sin ningún otro título.

SECCIONES:

1. Los ingredientes — Tipos de datos primitivos (3 min)
- Enteros con signo: sbyte, short, int, long (memoria que ocupan)
- Enteros sin signo: byte, ushort, uint, ulong
- Decimales: float, double, decimal (precisión)
- Otros: bool, char, string
- "¿Qué tipo usarías para el precio de una skin? Para dinero, SIEMPRE decimal"
- Netflix almacena email (string), edad (int), premium (bool)

2. Las vasijas — Variables, constantes y literales (3 min)
- Variable: contenedor con nombre, tipo y valor que puede cambiar
- Declaración: `int edad = 22;` o `var edad = 22;` (inferencia)
- var: el compilador deduce el tipo, pero NO puede cambiar después
- const: valor fijo resuelto en compilación, busca y reemplaza
- Literales: 42, 3.14, "hola", true
- Spotify guarda playlist (string[]), nivel (int), const PRECIO = 9.99

3. Las medidas — Tamaños y rangos (2 min)
- Cada tipo tiene un tamaño fijo en bytes
- sbyte: -128 a 127. byte: 0 a 255. int: hasta 2.147 millones
- Si unPokemon tiene 300 CP, byte no sirve (máximo 255)
- Netflix necesita long para contar vistas (miles de millones)

4. La receta — Operadores aritméticos y asignación (3 min)
- Básicos: +, -, *, /, %. División entera: 10/3 = 3
- Asignación: =, +=, -=, *=, /=. Cuidado: "=+" no es "+="
- Uber calcula precio: distancia * tarifa + comisión

5. El termostato — Relacionales y lógicos (2 min)
- Relacionales: ==, !=, <, >, <=, >= (devuelven bool)
- Lógicos: && (Y), || (O), ! (NO). Precedencia: NOT > AND > OR
- De Morgan: !(A && B) = !A || !B
- Amazon verifica: tieneCuenta && (tieneDireccion || recogeEnTienda)

6. La navaja suiza — Ternario y coalescencia (2 min)
- Ternario: condición ? valorSiTrue : valorSiFalse
- Coalescencia: ?? (si es null, usa el otro valor)
- Nullable: int?, string? para valores que pueden no existir
- YouTube muestra "Anónimo" si no tienes nombre

CIERRE: "Para dinero usa decimal, para texto string, y siempre trata los nulos con ?? y ?."

# VÍDEO 3: Entrada, Salida y Conversiones de Tipo (15 min)

## Para NotebookLM: Generar Vídeo de Ejemplo Práctico

---
Crea un vídeo de contenido para la asignatura Programación del CFGS de Desarrollo de Aplicaciones Web, primer curso, curso 2026/2027, en el IES Luis Vives de Leganés. El profesor es José Luis González Sánchez.

Duración: 15 minutos. Idioma: español de España (castellano), nunca otra variante. Voz masculina. Tono didáctico y cercano.

Metáfora visual: "La Cocina". El servicio es la entrada/salida, la balanza son las conversiones, el cocinero es el programador.

PORTADA: Título EXACTO "Entrada, Salida y Conversiones de Tipo". Subtítulo: Programación · 1DAW · IES Luis Vives de Leganés · 2026/2027. Sin ningún otro título.

SECCIONES:

1. El servicio — Entrada de datos (3 min)
- Console.ReadLine(): SIEMPRE devuelve string, NUNCA un número
- El usuario puede escribir "abc" cuando esperas un número
- int.Parse(): convierte pero lanza excepción si falla
- int.TryParse(): devuelve bool, no petan, más seguro
- "Siempre valida la entrada, nunca confíes en lo que escribe el usuario"
- Glovo pide tu dirección con ReadLine

2. El plato — Salida de datos (3 min)
- Console.WriteLine(): escribe y salta de línea
- Console.Write(): escribe sin salto de línea
- Interpolación: $"{nombre} tiene {edad} años"
- Concatenación: "texto" + variable (forma antigua)
- {precio:F2} para mostrar 2 decimales
- Netflix muestra "Recomendado para {nombre}" con interpolación

3. La balanza — Conversiones implícitas (2 min)
- El compilador convierte solo cuando no hay pérdida de datos
- int a long: OK. int a double: OK
- bool y string NUNCA se convierten entre sí
- Sumar int + double da double automáticamente
- "Si el compilador convierte todo solo, puede haber sorpresas"

4. La pinza — Conversiones explícitas (3 min)
- Casting: double precio = 19.99; int entero = (int)precio; → 19
- Pierde datos: los decimales se eliminan
- Útil para mostrar solo la parte entera, peligroso si el número es grande
- Convert.ToInt32() acepta null y devuelve 0
- Netflix redondea duración de double a int para mostrar solo minutos

5. El recetario — Texto a número (3 min)
- int.Parse("123") funciona, "abc" lanza FormatException
- int.TryParse("abc", out var r) devuelve false, seguro
- Siempre TryParse con entrada de usuario
- decimal.TryParse para precios, double.TryParse para decimales
- Amazon pide precio: TryParse evita el crash con "abc"

6. El improvisado — Errores comunes (1 min)
- int para dinero: 10/3 = 3 en vez de 3.33 → usar decimal
- No validar con TryParse
- Confundir Write y WriteLine
- Olvidar que ReadLine devuelve string
- Un cajero que no valida podría aceptar "hola" como cantidad

CIERRE: "Lee con ReadLine (string), valida con TryParse, y para dinero usa decimal."
"Like y Suscripción para codificar un montón y nos vemos en el próximo deploy."
