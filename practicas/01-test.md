### Bloque 1: Fundamentos de la Programación (Preguntas 1-8)

1.  **Según las fuentes del tema, ¿qué es un algoritmo?**
    a) El código fuente de un programa informático escrito en un lenguaje de programación concreto.
    b) Una secuencia ordenada y finita de pasos, descrita sin ambigüedades, que conduce a la resolución de un problema dado.
    c) Un tipo de diagrama que se utiliza para representar la estructura de un programa.
    d) Un conjunto de herramientas que permiten depurar errores en tiempo de ejecución.

2.  **¿Cuál de las siguientes opciones describe correctamente las características fundamentales que debe cumplir todo algoritmo?**
    a) Debe ser preciso, finito, tener cero o más entradas, producir un resultado y ser flexible durante su ejecución.
    b) Debe ser preciso, finito, tener al menos una entrada, producir un resultado y ser comprensible.
    c) Debe ser preciso, infinito, tener una entrada, producir un resultado y ser eficiente.
    d) Debe ser ambiguo, finito, tener entradas, producir un resultado y ser escalable.

3.  **¿Qué estrategia de diseño de algoritmos consiste en descomponer un problema complejo en subproblemas más pequeños y manejables hasta que cada uno se pueda resolver de forma sencilla?**
    a) Abstracción por generalización.
    b) Divide y vencerás (descomposición).
    c) Refactorización iterativa.
    d) Programación orientada a eventos.

4.  **En el ciclo de vida del desarrollo de software, ¿en qué fase se genera el documento de Especificación de Requisitos del Software (ERS)?**
    a) En la fase de Diseño, donde se define la arquitectura técnica.
    b) En la fase de Análisis, donde se recogen y documentan las necesidades del cliente.
    c) En la fase de Codificación, donde se escribe el código fuente.
    d) En la fase de Pruebas, donde se validan los requisitos implementados.

5.  **¿Cuál de los siguientes tipos de mantenimiento de software tiene como objetivo principal la incorporación de nuevas funcionalidades al sistema ya existente?**
    a) Mantenimiento correctivo.
    b) Mantenimiento perfectivo.
    c) Mantenimiento evolutivo.
    d) Mantenimiento adaptativo.

6.  **Según las fuentes, ¿qué tipo de lenguaje de programación se clasifica como de "alto nivel" y cuál es su principal ventaja respecto a los lenguajes de bajo nivel?**
    a) Los lenguajes de alto nivel son más rápidos en ejecución porque se traducen directamente a código máquina.
    b) Los lenguajes de alto nivel son más cercanos al lenguaje humano y permiten la portabilidad entre diferentes plataformas.
    c) Los lenguajes de alto nivel no necesitan compilador ni intérprete para su ejecución.
    d) Los lenguajes de alto nivel solo funcionan en sistemas operativos específicos.

7.  **¿Qué pilar de la Programación Orientada a Objetos (POO) permite ocultar los detalles internos de un objeto y exponer únicamente lo necesario al exterior?**
    a) Herencia.
    b) Polimorfismo.
    c) Abstracción.
    d) Encapsulamiento.

8.  **La fase de Documentación en el desarrollo de software incluye:**
    a) Únicamente los manuales de usuario finales.
    b) Documentación técnica, documentación de usuario e instrucciones de instalación.
    c) Solo los comentarios insertados en el código fuente.
    d) No se considera una fase formal del ciclo de vida del software.

### Bloque 2: Algoritmos y Paradigmas (Preguntas 9-16)

9.  **¿Qué paradigma de programación se caracteriza por indicar al ordenador CÓMO realizar las cosas, mediante una secuencia de instrucciones paso a paso?**
    a) Declarativo.
    b) Funcional puro.
    c) Imperativo.
    d) Reactivo.

10. **En un paradigma declarativo, ¿qué se describe en el código del programa?**
    a) La secuencia exacta de pasos que el ordenador debe ejecutar.
    b) Qué se quiere obtener como resultado, sin especificar los pasos para conseguirlo.
    c) Los objetos que componen el sistema y sus relaciones.
    d) Las funciones puras y su composición sin efectos secundarios.

11. **¿Qué característica fundamental define a la programación funcional y la diferencia de otros paradigmas?**
    a) El uso exclusivo de clases y objetos para organizar el código.
    b) Las funciones puras, sin efectos secundarios y sin variación de estado.
    c) La ejecución secuencial estricta de instrucciones en un orden determinado.
    d) El uso de interfaces gráficas para la interacción con el usuario.

12. **C# se clasifica como un lenguaje de programación:**
    a) Exclusivamente imperativo.
    b) Exclusivamente orientado a objetos.
    c) Multiparadigma (soporta imperativo, OO, funcional, etc.).
    d) Exclusivamente funcional.

13. **El paradigma de programación que organiza el código en objetos que contienen datos (atributos) y comportamientos (métodos) se denomina:**
    a) Paradigma imperativo.
    b) Paradigma modular.
    c) Programación Orientada a Objetos (POO).
    d) Paradigma declarativo.

14. **¿En qué consiste la diferencia principal entre la programación imperativa clásica y la programación estructurada?**
    a) No existe diferencia; son sinónimos.
    b) La programación estructurada utiliza `goto` de forma libre, la imperativa no.
    c) La programación estructurada organiza el código con estructuras de control (`if`, `for`, `while`) eliminando el uso de `goto`.
    d) La programación imperativa es más moderna que la estructurada.

15. **¿Qué paradigma de programación se activa como respuesta a acciones del usuario (clics, pulsaciones de tecla, eventos del sistema)?**
    a) Paradigma basado en procesos.
    b) Paradigma basado en eventos.
    c) Paradigma basado en objetos.
    d) Paradigma basado en reglas.

16. **¿Cuál de las siguientes opciones describe correctamente la diferencia entre un algoritmo eficiente y uno correcto?**
    a) Un algoritmo correcto es aquel que funciona sin errores; un eficiente es aquel que utiliza la mínima cantidad de recursos posible para resolver el problema.
    b) Un algoritmo eficiente siempre es correcto, pero un algoritmo correcto no siempre es eficiente.
    c) Un algoritmo eficiente se ejecuta más rápido, pero puede producir resultados erróneos.
    d) No hay diferencia; ambos conceptos significan lo mismo.

### Bloque 3: Lenguajes de Programación (Preguntas 17-24)

17. **¿Cómo se denomina el conjunto de símbolos y palabras especiales que constituyen el vocabulario de un lenguaje de programación?**
    a) Sintaxis.
    b) Semántica.
    c) Léxico (alfabeto del lenguaje).
    d) Gramática libre de contexto.

18. **La sentencia `int x = "hola";` en C# es:**
    a) Sintácticamente correcta y semánticamente correcta.
    b) Sintácticamente incorrecta.
    c) Sintácticamente correcta pero semánticamente incorrecta (error de tipos).
    d) Semánticamente correcta pero sintácticamente incorrecta.

19. **¿Qué tipo de lenguaje de programación necesita un compilador que traduce el código fuente a código binario en un solo paso antes de la ejecución, lo que resulta en una ejecución muy eficiente?**
    a) Lenguaje interpretado.
    b) Lenguaje de script.
    c) Lenguaje compilado.
    d) Lenguaje de máquina virtual.

20. **Un lenguaje que compila a código intermedio (bytecode) y luego se ejecuta en una máquina virtual se clasifica como:**
    a) Lenguaje compilado a código máquina nativo.
    b) Lenguaje interpretado directamente.
    c) Lenguaje mixto o virtual.
    d) Lenguaje de bajo nivel.

21. **¿Qué es la transpilación en el contexto de los lenguajes de programación?**
    a) El proceso de traducir código de bajo nivel a código de alto nivel.
    b) El proceso de traducir código de un lenguaje de alto nivel a otro lenguaje de alto nivel similar.
    c) El proceso de interpretar código línea a línea durante la ejecución.
    d) El proceso de compilar código fuente directamente a código máquina nativo.

22. **¿Qué significa que un lenguaje de programación es de "Tipado Fuerte"?**
    a) Permite conversiones automáticas entre tipos de datos incompatibles.
    b) Los tipos de datos se verifican exclusivamente en tiempo de ejecución.
    c) No permite conversiones implícitas entre tipos incompatibles, obligando a conversiones explícitas.
    d) El programador no necesita declarar los tipos de las variables.

23. **En un lenguaje de programación de "Tipado Estático", ¿cuándo se verifica el tipo de las variables?**
    a) En tiempo de ejecución, cuando se asigna un valor.
    b) En tiempo de compilación, antes de que el programa se ejecute.
    c) Solo al inicio del programa, durante la inicialización.
    d) Nunca se verifica; es responsabilidad del programador.

24. **TypeScript es un ejemplo de:**
    a) Lenguaje compilado directamente a código máquina nativo.
    b) Lenguaje interpretado directamente por el navegador.
    c) Lenguaje transpilado a JavaScript para su ejecución.
    d) Lenguaje de bajo nivel close al hardware.
