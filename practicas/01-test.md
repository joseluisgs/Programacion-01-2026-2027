### Bloque 1: Fundamentos de la Programación (Preguntas 1-8)

1.  **¿Qué es un algoritmo?**
    a) El código fuente de un programa listo para ser ejecutado.
    b) Una herramienta gráfica para depurar errores en el software.
    c) Una secuencia ordenada de pasos, descrita sin ambigüedades, que conducen a la solución de un problema dado.
    d) Un lenguaje de programación de alto nivel.

2.  **¿Cuál de las siguientes afirmaciones NO es una característica fundamental de un algoritmo?**
    a) Debe ser preciso.
    b) Debe ser finito.
    c) Debe ser adaptable a requisitos cambiantes durante su ejecución.
    d) Debe producir un resultado (salida).

3.  **¿Cuál de las siguientes NO es una característica adicional de un buen algoritmo?**
    a) Correcto.
    b) Eficiente.
    c) Comprensible.
    d) Interactivo.

4.  **¿Qué estrategia de diseño consiste en descomponer un problema complejo en problemas más pequeños hasta que cada uno sea fácil de resolver?**
    a) Encapsulación.
    b) Abstracción.
    c) Divide y vencerás.
    d) Modularidad.

5.  **¿En qué fase del ciclo de vida del software se escribe el código fuente?**
    a) Diseño.
    b) Análisis.
    c) Codificación.
    d) Pruebas.

6.  **El documento de Especificación de Requisitos del Software (ERS) se elabora principalmente en la fase de:**
    a) Diseño.
    b) Codificación.
    c) Análisis.
    d) Mantenimiento.

7.  **¿Qué tipo de mantenimiento corrige errores o fallos en el software?**
    a) Evolutivo.
    b) Perfectivo.
    c) Correctivo.
    d) Adaptativo.

8.  **La fase de Documentación incluye:**
    a) Solo manuales de usuario.
    b) Documentación técnica, de usuario e instalación.
    c) Solo comentarios en el código.
    d) No es una fase del ciclo de vida.

### Bloque 2: Algoritmos y Paradigmas (Preguntas 9-16)

9.  **¿Qué paradigma de programación se basa en decir al ordenador CÓMO hacer las cosas, paso a paso?**
    a) Declarativo.
    b) Funcional.
    c) Imperativo.
    d) Orientado a Objetos.

10. **En un paradigma declarativo, ¿qué se describe?**
    a) Cómo hacer cada paso.
    b) Qué se quiere obtener, sin especificar cómo.
    c) Los objetos que componen el sistema.
    d) Las funciones puras sin estado.

11. **¿Qué característica define a la programación funcional?**
    a) Uso de clases y objetos.
    b) Funciones puras sin efectos secundarios.
    c) Instrucciones paso a paso.
    d) Uso de interfaces gráficas.

12. **C# es un lenguaje:**
    a) Solo imperativo.
    b) Solo orientado a objetos.
    c) Multiparadigma.
    d) Solo funcional.

13. **¿Qué paradigma organiza el código en objetos que contienen datos (atributos) y comportamientos (métodos)?**
    a) Imperativo.
    b) Modular.
    c) Orientado a Objetos (POO).
    d) Declarativo.

14. **El paradigma basado en eventos se activa cuando:**
    a) El usuario escribe código.
    b) Se produce una acción del usuario (clic, pulsación de tecla, etc.).
    c) El compilador termina de traducir.
    d) Se inicia el ordenador.

15. **¿Cuál es la diferencia entre programación imperativa y estructurada?**
    a) No hay diferencia.
    b) La estructurada usa `goto`, la imperativa no.
    c) La estructurada organiza el código con `if`, `for`, `while` (sin `goto`).
    d) La imperativa es más moderna.

16. **¿Qué pilar de la POO oculta los datos internos de un objeto y solo muestra lo necesario?**
    a) Herencia.
    b) Polimorfismo.
    c) Abstracción.
    d) Encapsulamiento.

### Bloque 3: Lenguajes de Programación (Preguntas 17-24)

17. **¿Cómo se denomina el conjunto de símbolos y palabras especiales que constituye el vocabulario de un lenguaje de programación?**
    a) Sintaxis.
    b) Semántica.
    c) Léxico.
    d) Gramática.

18. **La sentencia `int x = "hola";` es:**
    a) Sintácticamente correcta.
    b) Semánticamente correcta.
    c) Sintácticamente incorrecta.
    d) Sintácticamente correcta pero semánticamente incorrecta.

19. **¿Qué tipo de lenguaje necesita un compilador que traduce el código fuente a código binario en un solo paso?**
    a) Interpretado.
    b) Mixto.
    c) Compilado.
    d) Script.

20. **Un lenguaje que compila a código intermedio (bytecode) y luego se ejecuta en una máquina virtual se clasifica como:**
    a) Compilado.
    b) Interpretado.
    c) Mixto o virtual.
    d) De bajo nivel.

21. **¿Qué es la transpilación?**
    a) Traducir código de bajo nivel a alto nivel.
    b) Traducir código de un lenguaje de alto nivel a otro de alto nivel similar.
    c) Interpretar código línea a línea.
    d) Compilar código a máquina nativa.

22. **¿Qué significa que un lenguaje es de "Tipado Fuerte"?**
    a) Permite conversiones automáticas entre tipos incompatibles.
    b) Los tipos se verifican en ejecución.
    c) No permite conversiones implícitas entre tipos incompatibles.
    d) El programador no necesita declarar tipos.

23. **En un lenguaje de "Tipado Estático", ¿cuándo se verifica el tipo de las variables?**
    a) En tiempo de ejecución.
    b) En tiempo de compilación.
    c) Solo al inicio del programa.
    d) No se verifica nunca.

24. **TypeScript es un ejemplo de:**
    a) Lenguaje compilado a máquina nativa.
    b) Lenguaje interpretado directamente.
    c) Lenguaje transpilado a JavaScript.
    d) Lenguaje de bajo nivel.
