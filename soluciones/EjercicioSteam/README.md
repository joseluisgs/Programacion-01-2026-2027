# Ejercicio 24: Resumen de Compra en Steam

## Conceptos aplicados
- Tipos: `decimal`, `int`, `bool`
- Constantes: `const`
- Operadores: `*`, `>`, `&&`, `?:`
- Entrada/salida: `Console.ReadLine`, `Console.WriteLine`
- Conversión: `decimal.TryParse`, `int.TryParse`
- Interpolación: `$"..."`

## Comandos

```bash
mkdir EjercicioSteam
cd EjercicioSteam
dotnet new sln --name EjercicioSteam
dotnet new console --name EjercicioSteam
dotnet sln add EjercicioSteam/EjercicioSteam.csproj
dotnet run
```
