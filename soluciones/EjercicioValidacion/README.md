# Ejercicio 47: Validación de Partida

## Conceptos aplicados
- Tipos: `double`, `int`, `bool`
- Constantes: `const`
- Operadores lógicos: `&&`
- Operador ternario: `? :`
- Comparaciones: `<`, `>=`, `==`
- Interpolación: `$"..."`

## Comandos

```bash
mkdir EjercicioValidacion
cd EjercicioValidacion
dotnet new sln --name EjercicioValidacion
dotnet new console --name EjercicioValidacion
dotnet sln add EjercicioValidacion/EjercicioValidacion.csproj
dotnet run
```
